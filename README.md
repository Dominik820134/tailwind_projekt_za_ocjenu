# Glazbeni kutak Dominik - Web stranica

Višestranična web stranica za obrt **Glazbeni kutak Dominik** - specijaliziranu trgovinu gramofonskih ploča te servis gramofona u Koprivnici.

Projekt je izrađen u sklopu zadatka za oblikovanje web stranice pomoću Tailwind-a.

## Struktura projekta

TAILWIND_PROJEKT_ZA_OCJENU
>slike
<> index.html ==> sadrži početnu stranicu
<> kontakt.html ==> sadrži stranicu gdje nas možete kontaktirati
<> usluge.html ==> sadrži stranicu u kojoj piše što sve nudimo
